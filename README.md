# 📚 Book Market Analysis

> A data analysis project exploring book market trends, customer preferences, and reading behavior using SQL to generate insights that support product strategy and business decision-making.

---

# 📖 Project Overview

Understanding customer preferences is essential for digital platforms operating in the publishing industry. This project analyzes data from an online book service to uncover market trends, reader behavior, and factors influencing book popularity.

Using SQL queries, the analysis explores books, authors, publishers, ratings, and reviews to identify meaningful insights that can support the development of data-driven product strategies.

---

# 📂 Dataset

The project uses a relational database containing information about:

### Books

- Book ID
- Title
- Author
- Publisher
- Publication Date
- Number of Pages

### Authors

- Author ID
- Author Name

### Publishers

- Publisher ID
- Publisher Name

### Ratings

- Rating ID
- Book ID
- Username
- Rating Score

### Reviews

- Review ID
- Book ID
- Username
- Review Text

> **Note:** The original database is not included in this repository. The notebook contains the complete SQL queries, analysis, and business insights developed during the project.
